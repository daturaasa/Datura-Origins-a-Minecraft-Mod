# Datura Origins v1.0.0

Primeira versão estável do novo Datura Origins, refeito do zero para Fabric 1.21.1.

- 24 raças com modelos 3D animados, vantagens, fraquezas e uma habilidade ativa cada.
- Grimório de seleção com prévia 3D e música ambiente original.
- Raças definidas em JSON e abertas para addons.
- Comandos `/do race`, `/do race change`, `/do race set`, `/do race list` e comandos de teste.

Requer Fabric Loader, Fabric API e Java 21.

Esta versão substitui as anteriores (Dakura/Datura Origins até a v1.5.0), que foram feitas em outra base de código. Não use junto com versões antigas.
