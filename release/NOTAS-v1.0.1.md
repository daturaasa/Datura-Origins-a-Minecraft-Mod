# Datura Origins v1.0.1

Correções e melhorias da primeira versão estável.

- Mod traduzido: a interface, as raças, habilidades e mensagens seguem o idioma do Minecraft (português e inglês; os demais idiomas usam o inglês).
- Grimório e tela de seleção refeitos: minimalistas, com fundo liso, livro menor com aro de encantamentos, variantes como raças próprias e prévia que mostra a raça inteira.
- Modelos e animações revistos: caudas das raposas, Kitsunes e sereias; asas da fada em V; dragão maior com cauda que se enrola; chifres do bode, demônio e dríade.
- Bode pula 5 blocos sem carregar; correntes da Kitsune Corrompida prendem qualquer criatura; efeitos originais do Orbe Espiritual restaurados.
- README com guia para criar novas raças.

Requer Fabric Loader, Fabric API e Java 21.
